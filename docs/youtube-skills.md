# 유튜브 스킬 11개 — 따라 하기 체크리스트

원본: https://github.com/Jakeschincariol/youtube-agent-skill (MIT 라이선스)

이 저장소에는 이미 설치되어 있어요.

- 스킬 11개: `.claude/skills/yt-*`
- 내 말투 파일: `.claude/youtube/voice.md` (빈칸 채우기용 한국어 양식)

이 저장소로 Claude Code 세션을 열면 `/yt-script` 같은 명령이 바로 보입니다.

## 0단계. 설치 확인 (완료 ✅)

- [x] 스킬 11개를 `.claude/skills/` 에 복사
- [x] 클로드 스킬 목록에 `yt-script` 등 11개가 뜨는 것 확인
- [x] 계산 도구 6개가 파이썬 3에서 실행되는 것 확인

> **한국어 주의**: 계산 도구는 영어 단어를 기준으로 만들어졌어요.
> - `hookscore.py`(시작 문장 점수)는 한국어 문장을 거의 채점하지 못해요 (모두 WEAK로 나옴). 한국어 훅 점수는 참고만 하세요.
> - `title.py`(제목 검사)는 글자 수·숫자 검사는 되지만, 제목과 썸네일의 한국어 단어 중복은 못 잡아요.
> - `deadair.py`(편집 목록)의 무음 구간 찾기는 언어와 상관없이 잘 돼요. "음, 어" 같은 한국어 군더더기는 클로드가 눈으로 따로 봐 줘야 해요.

## 1단계. 내 말투 파일 채우기 (10분, 제일 중요)

1. 내 영상 3개의 자막을 준비해요.
   - 유튜브 스튜디오 → 콘텐츠 → 영상 → 자막 → `⋮` → 다운로드(.srt)
2. 클로드에게 이렇게 보내요.
   ```
   내 영상 3개의 자막이야. 이걸 읽고 .claude/youtube/voice.md 를 채워 줘.
   형식 칸에는 "한국어로 말한다"를 꼭 넣어 줘.
   [자막 붙여넣기]
   ```
3. 다 채워지면 "커밋하고 푸시해 줘"라고 해서 저장해 두세요. 저장하지 않으면 클라우드 세션이 끝날 때 사라져요.

- [ ] voice.md 완성

## 2단계. 뭘 만들지 정하기

```
/yt-viral
내 분야는 [예: 직장인 재테크]야. 평소보다 훨씬 잘 된 영상을 찾아서, 이번 주에 내 말투로 만들 수 있는 걸 골라줘.
```
- 공개된 목록만 읽어요. 내 계정에 로그인하지 않아요.
- 채널당 영상이 4개 이상 모여야 계산돼요. 참고할 채널 주소 3~5개를 같이 주면 좋아요.

```
/yt-plan
이번 주에 쓸 수 있는 시간은 [예: 평일 저녁 1시간씩, 주말 4시간]이야. 이 시간에 맞는 한 주 계획을 짜줘.
```

- [ ] 이번 주 주제 1개 정하기
- [ ] 한 주 일정표 받기

## 3단계. 만들기

```
/yt-script
영상 아이디어: [한 줄로]
```
→ 시작 문장 후보, 점수, `[ON SCREEN: …]` 이 붙은 대본이 나와요. 점수는 "다시 볼 곳" 신호일 뿐이에요.

```
/yt-package
제목: [내 제목]
썸네일 글자: [썸네일에 넣을 글자]
둘이 같은 말을 반복하는지, 잘리는지 봐줘.
```

촬영 뒤:
```
/yt-edit
[자막 파일 .srt 첨부 또는 붙여넣기] 편집할 곳 목록 만들어 줘.
```
```
/yt-shorts
[긴 영상 자막] 쇼츠 후보 찾아 줘.
```

- [ ] 대본
- [ ] 제목 + 썸네일 글자
- [ ] 편집 목록
- [ ] 쇼츠 후보

## 4단계. 올리기 전에

```
/yt-seo
[영상 제목과 대본 요약] 설명글이랑 이길 검색어 3개 정해 줘.
```
```
/yt-chapters
[자막 파일] 챕터 만들어 줘.
```
- 챕터 규칙: 첫 줄이 `0:00`, 3개 이상, 각 10초 이상이어야 해요. 도구가 대신 검사해 줘요.
- 업로드 버튼은 **내가 직접** 눌러요. 스킬은 "ship it, or change it?(올릴까요, 고칠까요?)"라고 묻고 멈춰요.

- [ ] 설명글 / 검색어
- [ ] 챕터
- [ ] 업로드 (직접)

## 5단계. 올린 뒤에

```
/yt-comment
[댓글 붙여넣기]
```
→ 질문 / 지적 / 칭찬 / 낚시, 네 무더기로 나누고 30단어 이내 답글과 고정할 댓글 1개를 골라 줘요.

```
/yt-retention
[시청 유지율 CSV 첨부] 영상 길이는 [예: 600]초야.
```
- 파일 받는 곳: 스튜디오 → 영상 → 분석 → 참여도 → 시청자 유지율 그래프 → 다운로드 아이콘
- 자막 파일도 같이 주면 "사람들이 나간 순간 무슨 말을 하고 있었는지"까지 알려 줘요.

- [ ] 댓글 답글
- [ ] 유지율 분석

## 6단계. 채널 점검

```
/yt-audit
내 채널: [채널 주소] 최근 제목 10개: [붙여넣기]
```
→ 고칠 것 **딱 하나**, 이미 잘하는 것 세 가지, 아직 하지 말 것으로 끝나요.

- [ ] 고칠 것 1개 정하기 → 다음 영상 주제 정할 때(2단계) 다시 쓰기
